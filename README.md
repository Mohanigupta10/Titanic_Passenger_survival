# Titanic Passenger Survival Study

## Objective
To analyze the Titanic dataset and identify factors that influenced passenger survival.

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Google Colab

## Analysis Performed
- Data Exploration
- Missing Value Analysis
- Survival Count Analysis
- Gender vs Survival Analysis
- Passenger Class vs Survival Analysis
- Age Distribution Analysis

## Key Findings
- Female passengers had a higher survival rate than males.
- First-class passengers survived more frequently.
- Third-class passengers had the lowest survival rate.
- Passenger class and gender significantly affected survival.

## Conclusion
Gender and passenger class were the most important factors influencing survival on the Titanic.
